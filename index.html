Opciones de hosting gratuito

Estas plataformas pueden publicar sitios estáticos compuestos por HTML, CSS y JavaScript. Revisa sus condiciones y límites antes de utilizarlas.

Cloudflare Pages

Publicación de archivos estáticos desde Git o carga directa. Buena opción para una web de demostración.

Sitio oficial ↗

Netlify

Flujo sencillo de despliegue y vistas previas. El plan gratuito tiene límites de uso que pueden cambiar.

Sitio oficial ↗

GitHub Pages

Publica sitios estáticos desde un repositorio. Está orientado a proyectos, documentación y páginas personales; revisa las restricciones de uso comercial.

Sitio oficial ↗

Vercel

Despliegue conectado a Git y soporte para varios frameworks. El plan Hobby tiene condiciones de uso no comercial.

Sitio oficial ↗

Render

Ofrece publicación de sitios estáticos y servicios web; verifica cuotas, disponibilidad y límites de cada plan.
